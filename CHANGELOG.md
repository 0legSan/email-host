# Changelog

## 0.1.0, 2026-11-11

Stable application release. Promotes the tested beta runtime without application code or dependency changes. New fixed-version bundles use `0.1.0`; the previous beta remains available.

Installation verification and unverified maintenance procedures remain documented separately in [the installation guide](docs/installation.md). Existing installations are not automatically upgraded by this release.

## 0.1.0-beta.2, 2026-11-11

First public installation beta.

- Ready Docker bundles for Linux amd64 and arm64, delivered from the project website.
- One-command wizards for standalone Caddy, existing Traefik and host Nginx.
- Generated owner access, persistent secrets, safe retry and image/checksum validation.
- Repository screenshots, bilingual setup guides, architecture map, agent instructions, FAQ, CI and third-party notices.

This is not a stable release. See [verification scope and limits](docs/installation.md) before using real mail. Re-running installation is not an upgrade procedure.
